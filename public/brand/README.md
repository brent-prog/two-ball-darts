# Two Ball Darts Brand Assets

Canonical rebrand assets for the app and marketing site.

## Primary assets
- `twoball-mark.svg` - approved red/ivory master mark
- `twoball-logo-horizontal.svg` - primary full-name lockup
- `twoball-logo-stacked.svg` - secondary stacked lockup with tagline
- `twoball-app-icon.svg` - very dark green app icon treatment

## Brand colours
- Background Green `#02140F`
- Surface Green `#071C16`
- Golf Green `#0E5A3A`
- TwoBall Red `#EF0014`
- Ivory `#F4EFE2`
- Muted Text `#A7B3A9`
- Gold `#E4C15A`
- Hazard Blue `#1E5BFF` - reserved for the custom physical board hazard treatment

## Typography
- Logo / display: Barlow Condensed Black (900)
- UI headings: Barlow Condensed 700-900
- Body/UI: Inter

Do not redraw or substitute the mark. The custom TwoBall dartboard remains a separate visual asset and should not be recreated inside the logo.
